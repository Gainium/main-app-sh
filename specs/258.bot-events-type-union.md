# 258 — getBotEvents: union of event types

## Behaviour

`getBotEventsInput.types: [String]` (optional) filters a bot's events to those matching ANY of the
listed types. The result is AND-ed with the DataGrid `filterModel` (time, pair, search) and with
`category`.

- `orders`: `event` is one of `Order`, `Order error`, `Take Profit`, `Stop Loss`.
- `deals`: tied to a deal and not an alert (the same condition as `category: "deals"`).
- `errors` / `warnings`: `type` is `error` / `warning`.

Unknown values are ignored. Missing or empty (or nothing recognised) means no type filter.
Duplicates collapse. The DataGrid mapping can't express this, because it joins all of its items
with a single `$and` or `$or`.

The per-category `counts` are computed with the same base conditions, so they respect the
selection just as they respect `filterModel`.

## Invariants

None: read-only query, and no persisted state changes.
