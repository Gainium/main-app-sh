# 191 — A fixed-price take-profit edit re-places the safety orders

Bug spec. Related: the take-profit-only deal edit (`isTpOnlyDealEdit`,
`tpOnlyDealKeys` in `src/bot/dcaHelper.ts`).

## §1 Definition

### §1.1 Expected

- **§1.1.1** A DCA deal edit that changes only the take profit, whether it is
  set as a percentage or as a fixed price, cancels and re-places the
  take-profit order and leaves every resting safety order on the book.
- **§1.1.2** An edit that also changes anything else (order count, step,
  sizes, stop loss, …) still cancels and re-places the whole ladder.

### §1.2 Actual

- **§1.2.1** When the take profit is set as a fixed price, the dashboard's
  patch carries `useFixedTPPrices` and `fixedTpPrice` next to `tpPerc` and
  `multiTp`. Neither key is in `tpOnlyDealKeys`, so `isTpOnlyDealEdit` returns
  false and `rebuildDealOrders` runs the full path: every safety order is
  cancelled and placed again at the same price and size before the new take
  profit goes in. Each level loses its place in the book.

## §2 Evidence

- A production `updateDealSettings` call on an open DCA deal sent
  `{tpPerc, multiTp:[{…, fixed}], useFixedTPPrices: true, fixedTpPrice}`. The
  deal's order rows show the old take profit cancelled, then all five safety
  orders cancelled and re-placed at the same prices and sizes within three
  seconds, then the new take profit at the fixed price.
- `useFixedTPPrices` and `fixedTpPrice` are read only by take-profit code:
  `getTPOrder` (single and multi-TP price, notional floor), `getTrailingSettings`
  and the settings resolver that derives `useFixedTPPrices`. Nothing that sizes
  or prices the safety-order ladder reads them.

## §3 Assumption

Hypothesis: the only reason a fixed-price take-profit edit misses the
take-profit-only path is that the two fixed-price keys are absent from
`tpOnlyDealKeys`. Adding them makes the same patch take that path, and §1.1.2
is unaffected because any non-take-profit key in the patch still fails the
`every` check.

## §4 Fix

- **§4.1** Add `useFixedTPPrices` and `fixedTpPrice` to `tpOnlyDealKeys`.
