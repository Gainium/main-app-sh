# 132 — The Deal Returns series stops at the newest 500 closed deals

DCA / Combo bots · `core/src/graphql/resolvers.ts` (`getBotProfitChartData`)
· `core/src/utils/dealReturn.ts`

## 1. Definition

### 1.1 Expected

The Deal Returns chart of a bot plots one point for every closed deal the
bot has, over the whole time axis the dashboard draws for it.

### 1.2 Actual

`getBotProfitChartData` returns at most the newest 500 closed deals. The
current dashboard draws the Deal Returns panel on the same time axis as the
Performance panel above it (the bot's whole life), so on any bot with more
than 500 closed deals the older part of the Deal Returns panel is empty.

## 2. Evidence

- A live DCA bot with 1507 closed deals (`getBotDeals` status `closed`,
  `total: 1507`): `getBotProfitChartData` returns exactly 500 points, the
  oldest closed 2026-09-22T23:20Z; every deal before that is missing from the
  chart while the deals table lists it.
- Code path: the aggregation ends with `{ $sort: { closeTime: -1 } },
  { $limit: 500 }`. The cap predates the dashboards' shared axis (it came with
  the original `botProfitChart` read, `{ sort: { time: -1 }, limit: 500 }`)
  and was carried over unchanged when spec-less fix #564 rebuilt the series
  from closed deals.
- Scale: the largest DCA bot holds ~48k deals. The projected series is
  `{ value, time }` per deal, ~2 MB of JSON at that size; the sort holds the
  projected deal fields only.

## 3. Assumption (root cause hypothesis)

The `$limit: 500` stage is the only thing cutting the series short. Removing
it returns every closed deal; nothing else in the pipeline or the consumers
truncates the series.

## 4. Required behaviour

- §4.1 The pipeline has no stage that bounds the number of deals returned
  (`$limit`, `$sample`, `$skip`).
- §4.2 The deal set is unchanged: the user's own deals of that bot, status
  `closed` or `canceled` (the set the deals table calls "closed").
- §4.3 Order is unchanged: newest close first.
- §4.4 The per-deal return value (`dealReturnPercentage`) is unchanged.
