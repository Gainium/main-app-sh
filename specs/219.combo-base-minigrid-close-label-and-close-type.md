# 219 — A combo deal closed by its completed base minigrid: label and close type

Bug spec.

## §1 Definition

### §1.1 Expected

When a combo deal's base minigrid completes, the engine closes the deal
(`DCACloseTriggerEnum.base`, shown as "Base Minigrid"). That close:

- §1.1.1 is recorded as `closeTrigger: base` however it ends — whether
  nothing is left to sell, or a closing order is needed and fills;
- §1.1.2 is sent with the deal close type the user chose for the combo deal
  (`comboTpLimit`: "Limit order" / "Market order"), exactly as the take profit
  and the close by timer (spec 204 §1.4) are.

### §1.2 Actual

- §1.2.1 `closeDeal`, booking a filled closing order, kept any recorded
  `closeTrigger` EXCEPT `base`, which it overwrote with `tp` (or `sl` for an
  SL order). So the same close reads "Base Minigrid" when the position was
  already flat (no closing order) and "take profit" when a closing order was
  needed — whatever the result of that order, including a loss.
- §1.2.2 Both places that send this close (`processMinigridOrder` and the
  start-up `recoverClosedBaseMinigrids`) hard-coded
  `CloseDCATypeEnum.closeByMarket`, ignoring `comboTpLimit`.

## §2 Evidence

- Production combo deals closed after the engine logged
  `Close deal … after base minigrid close`: about two thirds kept `base`, the
  rest carry `tp`; the trigger is the same in both groups.
- The close calls at `comboHelper.ts` pass `closeByMarket` literally; the
  timer close beside them already maps `comboTpLimit` to the close type.
- Reproduced with the real `recoverClosedBaseMinigrids`
  (`comboDealFunds.harness.spec.ts`, `spec 219 §3.2`): before the fix a bot
  set to limit is closed with `closeByMarket`.

## §3 Assumption (confirmed by the tests)

- §3.1 The label rule is: a trigger recorded on the deal wins; only an
  unlabelled deal closed by its own TP/SL order is labelled from that order.
  `base` gets no exception (`closeTriggerForFilledClose`, `dealOutcome.spec.ts`).
- §3.2 The base-minigrid close maps `comboTpLimit` like the timer close:
  limit → `closeByLimit`, not forced to market; otherwise `closeByMarket`,
  forced to market. The trigger stays `base`.

## §4 What must not move

- §4.1 DCA closes: nothing sets `base` outside combo, so their labels are
  unchanged; an unlabelled deal is still `tp` / `sl`.
- §4.2 The close by timer keeps spec 204's mapping (shared helper).
- §4.3 The flat-position settle after a grid refusal (spec 175) still closes
  at market: there is no position left to price.

## §5 Out of scope

- Deals already closed keep the label they were written with.
