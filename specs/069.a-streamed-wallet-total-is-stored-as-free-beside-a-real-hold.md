# 069 — A streamed wallet total is stored as `free` beside a real hold

Bug spec. Plan: `plans/069.a-streamed-wallet-total-is-stored-as-free-beside-a-real-hold.md`.
Pairs with `exchange-connector-sh` spec 015 (Kraken spot REST balance reports the
hold). Extends spec 003 (an absent `locked` leaves the stored hold alone).

## §1 Definition
- §1.1 Expected: for any balance row, `free` is what can be traded, `locked` is
  what open orders hold, and `free + locked` is the wallet total — whichever of
  the REST refresh or the user stream wrote last.
- §1.2 Actual: a stream item with no `locked` (Kraken spot v2) carries the wallet
  TOTAL in `free`, and `processBalanceUpdate` stores it verbatim. While the REST
  side wrote `locked: 0` this was merely "everything reads as free". Once REST
  writes the real hold (connector spec 015) the two disagree: the stream
  overwrites `free` with the total, `locked` keeps the hold, and the row
  overstates the wallet by the held amount until the next REST refresh.

## §2 Evidence
- `src/utils/user.ts` `processBalanceUpdate`, `outboundAccountPosition` branch:
  `free: parseFloat(d.free)` on both write paths, and the live `balance` event is
  published from the raw items.
- `websocket-connector-sh` spec 002 §4.1–§4.2: spot v2 `free` = the item's
  `balance` (the new total), no `locked` field.

## §3 Assumption
The absence of `locked` is a reliable marker that `free` is a total: a producer
that knows the hold sends it (every other venue does). `balanceWrite.spec.ts`
"streamedFree" cases fail on a helper that returns the reported figure unchanged.

## §4 Required behaviour
- §4.1 An item with no `locked` is stored and published with
  `free = max(0, reported − stored locked)`; `locked` stays as stored (spec 003).
- §4.2 An item that carries `locked` is written exactly as before.
- §4.3 An unknown, negative or non-finite stored hold counts as 0 — the row then
  behaves as it did before this spec.
- §4.4 `free` is never negative.
- §4.5 The live `balance` event for such an item carries the same `free` and the
  stored `locked`, so the dashboard shows what the collection holds.
