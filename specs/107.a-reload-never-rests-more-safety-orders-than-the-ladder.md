# 107 — A reload never rests more safety orders than the ladder holds

Follow-up to specs 105 (Combo) and 106 (DCA). Both pair a rebuilt ladder level
with the order already resting at it, so a level whose price moved by a tick is
not placed a second time. Each pairing has a gap: DCA pairs by rank only when
the counts match, and Combo pairs by `dcaLevel`, which an order may not carry.
In either gap the restart order check falls back to exact-price matching and
places every unmatched level beside its resting order, as before.

This spec adds an invariant that holds whatever the pairing decided.

## §1 Definition

### §1.1 Expected

- **§1.1.1** After the restart order check, the number of `dealRegular` orders
  resting on a side of an open deal is at most the number of `dealRegular`
  levels on that side of the rebuilt ladder (`deal.currentOrders`, hidden
  levels excluded), counting the orders that were already resting.
- **§1.1.2** When the candidates to place would break §1.1.1, the check places
  as many as fit and refuses the rest. It refuses the candidates priced
  closest to an order already resting on that side, since a level one tick
  from a resting order is that order.
- **§1.1.3** Each refusal is logged as a warning on the bot naming the deal and
  the refused prices.
- **§1.1.4** Other order types (TP, SL, Combo minigrid levels) are not counted
  or capped.

### §1.2 Actual (before)

- **§1.2.1** A DCA deal whose ladder moved by a tick AND is missing one resting
  order got every shifted level placed again (spec 106 §1.1.2).
- **§1.2.2** A Combo deal whose resting order carries no `dcaLevel` got the
  shifted level placed beside it (spec 105 §4.2).

## §2 Why this is safe

The candidates are exactly the ladder levels that matched no resting order, so
`resting + candidates - ladder` equals the number of resting orders that match
no ladder level. The cap therefore only ever acts when such orders exist, and
it removes at most that many placements. A reload whose resting orders all
match the ladder is unchanged. Where the cap acts, the deal keeps the orders it
already holds and does not add more — never more exposure than before the
reload.
