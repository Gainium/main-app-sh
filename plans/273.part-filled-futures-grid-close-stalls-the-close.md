## Change

1. `src/bot/helper.ts` `processSellAtStop`: for futures the "already closing"
   guard matches only a `FILLED` close. Before the sweep, a new
   `settleRestingCloses()` cancels every resting close (`NEW` or
   `PARTIALLY_FILLED`) with `promotePartialToFilled: false` and books each
   executed part through `bookPartialClose()` (§4.1, §4.2, §4.5). Its outcome
   decides the rest: `filled` → handed to `handleUnknownOrder` and return
   (§4.4); `pending` → re-arm the timer, place nothing (§4.3); `refused` →
   reported once, no retry (§4.7); `settled` → the existing flow, which sizes
   the new close from the reduced `position.qty`.
2. `bookPartialClose()`: once per order (`closeLegBooked`, cleared with
   `positionBooked`), books `profitAfterPositionClosed(order, executed)` and
   folds the order into the position with the existing `calculatePosition`.
3. `profitAfterPositionClosed` takes an optional closed quantity, capped at the
   position. Without it, it is unchanged.
4. `stop(cancel)`: `settleRestingCloses()` runs before the sweep, and its result
   is ignored: nothing is placed (§4.6).
5. The re-arm moves into `retrySellAtStop()`, which also clears a pending timer
   so two re-price chains cannot run at once.

JIT tier 0: branches and two small private methods inside the legacy mixin.
No extraction.

## Blast radius

- Every futures grid close by limit now cancels its resting close through
  `settleRestingCloses` instead of `cancelAllOrder`. For a close that never
  filled the result is the same cancel (no promotion is involved when nothing
  executed). Grid orders still go through `cancelAllOrder`.
- `stop()` is also the end of every close that filled (`processFilledStop` →
  `stop(true)`): nothing is resting then, so the settle step returns at once.
- `profitAfterPositionClosed` is also called by `closeBotByTp` (core and the
  main-app override) without the new argument, so they are unchanged.
- The main-app parent does not override `processSellAtStop`; its `stop`
  override calls `super.stop` first.
- No contract, schema or event change. Core is public `main-app-sh`; `psh`
  bumps the pointer.
- Money: it changes which close orders are cancelled and books position and
  profit. Stop class "money".
