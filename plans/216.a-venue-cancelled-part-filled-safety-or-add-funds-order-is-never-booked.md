# Plan 216 — book a part-filled `dealRegular` the venue cancels

Spec: `specs/216.a-venue-cancelled-part-filled-safety-or-add-funds-order-is-never-booked.md`.

## Build order

1. `src/bot/dca/canceledRegularFill.ts` (new, pure): `isDatedCanceledRegularFill`
   (the row `getAvgPrice` admits) and `shouldBookCanceledRegularFill` (the
   §1.1 / §1.3 decision). Built on `executedFillQty`, so a row with the
   no-venue-id placeholder answers 0 exactly as the ledger rebuild reads it.
2. `dcaHelper.processCanceledOrder`: a `dealRegular` arm ahead of the
   `!== dealTP` return, calling the new private `bookCanceledRegularFill`. It
   marks `processedFilled` and `ordersInBetweenUpdates` the way
   `processFilledOrder` does for a `dealRegular` fill, then calls `updateDeal`
   — no new booking code; the add-funds (`roa`) and safety-order branches
   already book from `executedQty`.
3. `dcaHelper.getAvgPrice`: admit `isDatedCanceledRegularFill` rows (§1.2).
   Stateless, so the average is the same after a restart.
4. Tests, version bump `1.123.14`, CHANGELOG.

## Decisions the spec left open

- **Own cancels are excluded** (§1.3.3) via `isOwnCancel`, the record spec 095
  writes before the venue round trip. The engine's cancel path promotes a
  part-filled cancel to FILLED (spec 156 §3) and owns its booking.
- **Not-open deals are excluded** (§1.3.5) in the predicate, not by relying on
  `updateDeal`: its closed-deal arm calls `sellRemainder`.
- JIT tier 2 (pure predicate). `updateDeal` is reused untouched (tier 0).

## Blast Radius

1. Call sites: `processCanceledOrder` is the DCA `onCanceled` callback only.
   `comboHelper` overrides it without `super` (combo is untouched). The main-app
   parent has no override of `processCanceledOrder`, `getAvgPrice` or the DCA
   `updateDeal`. `getAvgPrice` is private; its callers are `updateDeal`'s branches.
2. `core/` — shared with every main-app deploy (DCA + hedge-DCA workers).
3. No GraphQL/socket/queue/schema change. Deal fields written are the ones a
   fill already writes (`funds`, `pendingAddFunds`, balances, `avgPrice`, `size`).
4. Neighbouring suites that must stay green: `canceledReduceFunds.harness`,
   partial base-entry (048/101/125), TP partial cancel, `executedFill`.
