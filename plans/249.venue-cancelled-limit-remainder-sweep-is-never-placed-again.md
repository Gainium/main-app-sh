# Plan 249 — re-place a venue-cancelled LIMIT remainder sweep

## Build order

1. `dcaHelper.ts`: name the booking shape `LimitRemainderSweep` and add
   `retries`, `soldQty`, `soldQuote`. Add `LIMIT_REMAINDER_SWEEP_RETRIES = 3`.
2. Pull the booking out of `bookLimitRemainderSweep` into `bookLimitSweepSale`,
   which books the carried sale plus the order's own fill as one sale.
3. Add `retryCanceledLimitRemainderSweep(order)`: take the entry out of the map,
   carry what sold, and either re-place the unsold quantity (LIMIT, latest price,
   new id, `retries + 1`) or stop (own cancel, below minimums, cap) and book.
4. Call it from `processCanceledOrder` in `dcaHelper` (dealTP branch, before the
   spec-226 booking) and in `comboHelper` (before the dealGrid gate).

## Decisions left open by the spec

- The cap counts re-placements per sweep. One sweep exists per closed deal's
  remainder, so this is the brief's "3 per deal".
- A part fill is carried, not booked at once, because `sellRemainder`'s booking
  of a late fill also books the bought quantity (`qtyWithoutFee`, a level, the
  maker fee on it). Booking twice would count those twice. Carrying gives one
  booking identical to a single fill of the whole quantity.

## JIT tier

Tier 0/1: two small methods next to the spec-225 ones on the same class; no
extraction. The decision is short and reads state it already owns.

## Blast Radius

1. Call sites: `limitRemainderSweeps` is read by `sweepRemainderByLimit`,
   `bookLimitRemainderSweep` (DCA `processFilledOrder`, Combo
   `processFilledOrder`) and now the new method. Only ids placed by spec
   225 are in the map, so no other order reaches the new path.
2. `core/` (main-app-sh): shared with self-hosted. No types, GraphQL, socket
   or queue contract changes. The main-app parent does not override any of
   these methods.
3. Orders: a new reduce-only LIMIT sell of coins the account already holds,
   only after the venue cancelled the previous one, at most 3 times.
4. Other suites on this path, kept green: spec 225, 226 (`remainderSweepSelfTrade`),
   157, 112, 060, the cancel suites.
