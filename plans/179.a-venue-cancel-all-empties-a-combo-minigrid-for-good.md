3. `src/bot/comboHelper.ts` `loadMinigrids`, Redis branch: an open minigrid

## Decisions the spec left open

- **Threshold 60 s.** Spec 077's production refusal had zero venue-time rest,
  and the write-ahead `transactTime` is taken just before the send, so a
  refusal lands well inside a minute even when placement is slow. A resting
  order the venue cancels within its first minute falls back to the spec-077
  prune: the old behaviour, so nothing regresses. Each re-place has to rest
  for a minute before the next one, so an accepted-then-cancelled loop runs
  at most once a minute and cannot spin hot.
- **Re-place now, not at the next rebuild.** A kept level that is never
  re-placed keeps `grids` non-zero while the book is empty. That silences the
  sentinel invariant without fixing anything, and on a minigrid with no
  orders the only rebuild left is a worker restart. The re-place uses the
  existing `placeOrders` (deal mutex, close-in-flight guard, funding checks),
  with a fresh `CMB-GR` id, the same way `checkOrders` handles a cancelled
  order on a restart.
- **Not awaited.** `processCanceledOrder` runs inside the `processQueue` lock,
  and the fill callbacks are not awaited there either.

- **Heal on the Redis load, not by closing.** The only state that never
  repairs itself is a Redis copy with an empty ladder. The database load
  already rebuilds it, so the Redis branch does the same. Closing the minigrid
  would close a base minigrid's deal at market.

## JIT extraction tier

Tier 2 for the new decision (pure predicate, no I/O). `processCanceledOrder`
is otherwise left as is (Tier 0). The re-place is one guarded call.

## Blast radius

1. Call sites: `processCanceledOrder` is reached only from `processOrderQueue`'s
   `onCanceled` for combo bots. The predicate is new and has no other caller.
2. `core/` (main-app-sh): shared and public; the parent pointer needs a bump.
   Combo bots only. DCA/grid bots do not use this override.
3. Contracts: none. No GraphQL, socket, queue or schema change. A re-placed
   level is a normal grid order.
4. Tests that must stay green: `comboGridCancelLedger.spec.ts` (spec 077/130;
   its fixtures carry no placement time, so they take the refused path),
   `comboFlatDealGridRefusal.spec.ts` (spec 175), and the full core suite.
