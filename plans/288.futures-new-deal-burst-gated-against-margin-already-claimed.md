# Plan 288 — new-deal margin claims on futures

Spec: `specs/288.futures-new-deal-burst-gated-against-margin-already-claimed.md`.

## Steps

1. Pure class `src/bot/dca/newDealMarginClaims.ts`: `claim`, `claimed`,
   `placing`, `placed`, `release`, `settle(readStartedAt)`, plus the gated TTL.
2. `dcaHelper.checkBalance(…, claimMargin)`: record `readStartedAt` before the
   balance read; on futures + live + `claimMargin`, settle, subtract what is
   claimed, test, then claim synchronously on a pass.
3. `checkBalanceGate(symbol, claimMargin)` forwards the flag to the live read
   only.
4. `openNewDealBody`: both gate calls pass `true`; every early return between
   the gate and `placeBaseOrder` releases the claim; `placeBaseOrder` is
   wrapped so the claim is marked `placing` before it and `placed` in a
   `finally` after it.
5. Harness `src/bot/dca/newDealMarginClaims.harness.spec.ts` (red without
   claims, green with them).

## Blast Radius

- Repo: `main-app-sh` (core submodule) → every service consuming main-app
  core: cloud main-app bot workers and self-hosted main-app. No contract on
  the Danger List changes (no GraphQL, REST, socket, Redis, Mongo field).
- `checkBalance` callers: `checkBalanceGate` (new-deal gate and single-position
  add-entry gate), `applyNewDealSize` (scaled re-check), combo/other helpers
  that override or call it. The new parameter defaults to `false`, so every
  caller except the new-deal gate is byte-for-byte unchanged.
- `checkBalance` return type gains two optional fields (`marginClaim`,
  `claimed`); callers spreading or reading it are unaffected.
- Spot bots: `claims` is `null` unless `this.futures`; no behaviour change.
- Existing harness specs that drive `openNewDeal` with a stubbed
  `checkBalanceGate` (no `marginClaim`) — release/placing/placed are no-ops on
  `undefined`.
- Money: this gates order placement. Failure mode if wrong: a fundable deal
  is refused (quiet warning, re-tried next cycle) — never an extra or larger
  order. The 5 s re-check and the 10-minute gated TTL bound it.
