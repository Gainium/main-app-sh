# Plan 156 — A cancelled, partly filled KuCoin safety order is completed at market

Spec: `specs/156.kucoin-cancelled-safety-order-topped-up-at-market.md`.

## Solution

Add a pure predicate `isCancelledLimitSafetyOrder(order)` to
`src/bot/remainderFill.ts`, the module that already holds the per-venue
remainder predicates. It is true for a KuCoin spot LIMIT `dealRegular` row.
`buyRemainder` checks it inside its short-fill branch, before it records or sends
anything, logs the skip and returns the row unchanged, so the deal books what
filled.

Decided here, left open by the spec:

- **Discriminator: the order, not a cancel ledger.** The prod case (§2.1) was a
  cancel made on the exchange; the bot never asked for it, so `isOwnCancel`
  would not have matched. A resting KuCoin LIMIT order can only end short by
  being cancelled, whoever cancelled it, so the order type alone covers the
  owner's cancel, `cancelTerminalDealOrder` and an order-count reduction alike.
- **Scope: `dealRegular` only** (spec §1.3/§4.3).
- **No change to `@gainium/kucoin-api`** (spec §3).

JIT tier: 1 — the decision is pulled into the existing pure module and tested
there through the real `buyRemainder`; `buyRemainder` itself is not restructured.

## Build order

1. `src/bot/remainderFill.ts` — predicate.
2. `src/bot/main.ts` `buyRemainder` — the early return.
3. Tests green; core `CHANGELOG.md` + `package.json` patch bump.

## Blast Radius

1. Call sites: `buyRemainder` is private, reached only from
   `fillPartiallyFilledOrder` (stream consumer, placement response, settled base
   entry). The settled base entry is `dealStart`, untouched. No override in the
   main-app parent `src/`.
2. `core/` submodule (`main-app-sh`) — shared with every bot worker; the
   parent's pointer needs a bump at ship time.
3. No GraphQL/REST/socket/queue/collection shape changes. Fewer `br` rows are
   written for this one shape.
4. Other tests on this path: `unfillableTopUp.spec.ts`,
   `reduceOnlyRemainder.spec.ts`, `dca/settledBaseEntryCancelReplay.harness.spec.ts`,
   the full `npm test` suite.
