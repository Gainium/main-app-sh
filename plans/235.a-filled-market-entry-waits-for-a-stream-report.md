## Build order

1. `src/bot/marketEntryFill.ts` — pure predicates `isFullyExecutedMarketPartial`,
   `marketEntryNeedsRecheck`, and the re-check constants (45 s, 3 attempts).
2. `src/bot/main.ts` — apply `isFullyExecutedMarketPartial` (non-coin-margined)
   to `orderToPush` just before the placement answer is saved, and to the
   stream report in `processOrderQueue` after the existing Bybit block.
3. `src/bot/comboHelper.ts` — `armMarketEntryRecheck` after the non-FILLED
   placement answer in `placeBaseOrder`; `recheckMarketEntry` reads through the
   existing `_handleUnknownOrder(id, symbol, true)` and books a FILLED answer
   through the existing `handleUnknownOrder`; timers cleared in
   `clearClassProperties`.

Only `core/`; no parent change (parent `sendOrderToExchange` / `startDeal`
overrides delegate to super).

## Decisions left open by the spec

- Own timer map, not `dealTimersMap`: several checks read "a timer entry exists"
  as "an entry check is pending" (e.g. `hasPendingCheck` in the partial-entry
  settle), and Combo deliberately arms none there.
- `justPlaced = true` on the lookup: suspends the ladder's write-off, so a venue
  that cannot answer leaves the row for the reconnect/sweep paths (§1.3).
- JIT tier 2 for the predicates (pure, no I/O); the orchestration stays in the
  Combo class (tier 0 for the surrounding legacy code).

## Blast Radius

1. Call sites: the placement upgrade applies to every MARKET order sent by any
   bot type (base, TP close, br, splits) — a MARKET order with executed ≥
   requested is filled for all of them; `buyRemainder` acts only on executed <
   requested, so no remainder is bought. The stream upgrade widens the Bybit
   rule to every non-coin-margined venue; units are base on both sides there
   (`convertExecutionReportToOrder` converts contracts to base).
2. `core/` submodule — shared with the self-hosted build; pointer bump at push.
3. No GraphQL, socket, queue or schema change. No new persisted field.
4. Tests that exercise the path: `placementFillFeeOnce`, `comboPartialBaseEntry`,
   `comboUnbuiltBaseEntry.harness`, `reconnectCanceledBaseEntry.harness` — full
   `npm test` must stay green.
