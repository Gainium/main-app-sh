# Plan 074 — bound and qualify the refused-close restore

Spec: `specs/074.a-refused-close-re-arms-and-re-announces-itself-on-every-attempt.md`

## 1. Build order

1. `src/bot/dcaHelper.ts` — add `uncoveredCloseBackoff`, a `RetryBackoff`
   sibling of the existing `tpCloseBackoff` / `positionProbeBackoff` module
   constants. No new utility: `RetryBackoff` already is "a cooldown for
   rejections that will not succeed if we simply try again", is Redis-backed so
   the window survives a worker restart and is shared across the per-bot-type
   workers, and fails open.
2. `src/bot/dcaHelper.ts` — add `restoreOrReportRefusedClose(dealId, symbol,
   reason)`, the single seam holding §4.1's reason gate and §4.2's window. It
   calls the two existing methods; neither is modified.
3. `src/bot/dcaHelper.ts` — `closeDealById`'s terminal-refusal branch calls that
   one method instead of inlining the `covered` / report pair.
4. `src/bot/dca/refusedCloseRestore.harness.spec.ts` — extend with §4.1/§4.2
   fixtures. Back `RetryBackoff` with the Map-backed fake Redis idiom this repo
   already uses (`retryBackoff.memory.spec.ts`, `tpDustClose.harness.spec.ts`),
   so the window is observable and nothing touches a real Redis.
5. `package.json` + `CHANGELOG.md` in core, and the parent's pointer bump entry.

## 2. Contract decisions the spec left open

- **Reason predicate**: `this.isErrorNotEnoughBalance(reason)`, the existing
  `protected` member of the bot base, not a fresh import of
  `matchesNotEnoughBalance`. Same list, same behaviour, and it is the seam
  `isFeeSizingRejection` in this file already composes with.
- **Window ladder**: 5 min → 1 h (`minMs` 300_000, `maxMs` 3_600_000, default
  factor 2). Matches `dpp`/`nb`. Deliberately NOT `tpc`'s 1 → 15 min ladder:
  that one gates a close, where a blip costs unrealised profit; this one gates a
  fallback that runs behind a close which is still retrying.
- **`record()` placement**: after a failed restore, never before the attempt, so
  the window only ever opens on a restore that actually left the deal uncovered.
  `clear()` on success, matching how `positionProbeBackoff` and `tpCloseBackoff`
  release their windows.
- **Suppressed path**: `handleDebug`, not `handleWarn`. The condition is already
  reported; a suppressed attempt is diagnostics.

## 3. Blast radius

1. **Other call sites.** `restoreCloseAfterRefusal` and
   `reportUncoveredAfterRefusal` each have exactly one caller —
   `closeDealById`'s terminal-refusal branch — verified by grep over `src/`.
   Both keep their signatures and bodies, so nothing else can be affected.
   `isErrorNotEnoughBalance` is read, never changed.
2. **`core/` submodule.** Yes — this file is shared code, deployed to the cloud
   bot workers and to every self-hosted installation. The change is confined to
   one branch of one DCA/combo method; combo inherits it through the same mixin,
   which is intended (a combo close is refused the same way).
3. **Owned contracts.** None. No GraphQL/REST shape, no socket.io event name, no
   queue name or payload, no Mongo schema field. The one new external artefact
   is a Redis key namespace (`ucr:cd:<botId>:<dealId>`), which no other service
   reads. `botmessages` rows are unchanged in shape — there are simply fewer
   writes to the coalesced row.
4. **Other tests on this path.** `refusedCloseDeadlock.harness.spec.ts` (spec
   055) drives the same branch and must stay green; so must
   `trailingCloseRetry`, `trailingTpCloseRetry.harness`, `tpPriceRefusal.harness`
   and `tpDustClose.harness`, which all reach `closeDealById`'s refusal handling.
   Full `npm test` is the exit criterion.

### 3.1 Risk that is real

A funding shortfall that clears within the window is not re-armed by the
*restore* for up to an hour. It is still closed by the close path, which is
untouched and retries at the tick cadence — spec §5's assumption, and the reason
the ladder is allowed to reach an hour. If that assumption were wrong the
observed 6.7 restores per deal per 8 minutes could not exist, because there
would have been only one close attempt.
