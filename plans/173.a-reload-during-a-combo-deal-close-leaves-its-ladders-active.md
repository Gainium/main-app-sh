## Blast Radius

- Callers: `afterDealClose` is called only from `dcaHelper.processDealClose`,
  which runs for every deal close. The new write runs only when no ladder is
  in memory. That is the race, or a deal that never had ladders, such as one
  cancelled in `start`. It uses the `{ botId }` index: about 3.8k docs and
  3 ms on the affected bot, and the largest bot holds about 29k.
- Under `core/` — shared by main-app (cloud + self-hosted). No schema, GraphQL,
  socket or queue shape changes. Only the `status` of rows that already exist
  is written, with the value the normal path would have written.
- Not changed: which grid orders open deals place, and how or when deals
  close.
- Tests that must stay green: `combo*.spec.ts`, the core suite.
