# Plan 275 — futures grid quote profit omits the buy fee

## Build order

1. Red test `src/bot/gridFuturesBuyFeeProfit.spec.ts` (spec §5) — fails at
   0.01222257, the value recorded in prod.
2. `helper.ts` `createTransaction`: add `feeQuoteInProfit` after
   `totalQuote`, use it in the three quote-branch updates (spec §4).
3. Parent repo: restatement script (dry run default) and the observe
   invariant.

## Contract decisions

- The row keeps `feeQuote: 0` on a buy (spec §1.3): `orderFee.ts` and
  `feePaid` / `pairStats` read that shape, and writing the fee on both sides
  would double-count it there.
- Gated on `this.futures`, so spot bots are byte-for-byte unchanged.

## Blast radius

- Core `createTransaction` runs for every grid bot; the new value differs
  from `comQuote` only when `this.futures` and `comQuote === 0`.
- No schema, GraphQL, socket or REST shape changes. `profit.total` values
  move by the buy fees for futures quote-profit bots, which is the fix.
- Running bots keep their pre-fix total in memory; only fills after the
  deploy are booked net. The restatement script defaults to closed bots for
  that reason.
