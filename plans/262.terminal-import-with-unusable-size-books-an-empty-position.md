# 262 — plan

Spec: `specs/262.terminal-import-with-unusable-size-books-an-empty-position.md`.

## Solution (root cause per spec §3)

1. `src/bot/dca/importEntry.ts` (new, pure, Tier 2): `importEntryUsable(qty, price)`,
   `entryQtyMovesPosition(qty)`, `importEntryRefusalMessage(...)`.
2. `dcaHelper.getBaseOrder`, import branch: an unusable quantity/price builds no order. With a
   `dealId` (a real placement, not a sizing read) the user gets one bot message through
   `reportUserRefusal` (not `handleErrors`: a refused one-shot is not a broken bot).
3. `dcaHelper.placeBaseOrder`, import block: no order means return. Never fall through to the
   real-order path. The deal row is retired through `shouldDiscardUnbuiltBaseEntry` +
   `closeDealById(cancel)`, exactly as spec 039 already does for an entry that cannot be built.
4. `dcaHelper.startDeal`: a stored import row (`orderId -1`) that moved nothing cancels the deal
   instead of opening it. That is how a deal written before this fix is healed on its next replay
   (§1.3.2).
5. `dcaHelper.getAvgPrice`, futures branch: skip rows whose quantity moved nothing. A non-finite
   result is 0, as in the spot branch. `startDeal` falls back for `displayAvg` the way it already
   does for `avgPrice`.
6. Parent `main-app/src/bot/dcaHelper.ts` `startDeal` override: no `startDeal` webhook for the
   empty import that core now cancels.

## Blast radius

- Call sites of `getBaseOrder` with the import branch reachable: `placeBaseOrder` (dealId), and
  `refuseDealBelowExchangeMin` / `scaleDealSizes` / `checkBalance` (no dealId). All of them
  already treat `undefined` as "cannot size", and no message is sent without a dealId.
- `getAvgPrice` callers (`startDeal`, regular fill, add funds, settled-base repair, position
  merge): unchanged for any fold whose rows all moved something. Skipping a row of 0 only drops a
  0/0. The NaN case previously failed every save.
- `core/` is the public `main-app-sh`. No type, schema, GraphQL or socket contract changes.
- Tests that must stay green: `unbuiltBaseEntry`, `strandedStartClose`, `canceledRegularFill`,
  and the full core suite.
