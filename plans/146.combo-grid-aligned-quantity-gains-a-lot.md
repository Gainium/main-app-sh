   byte-for-byte the backtester's `MathHelper.gridRemainder`, so server-side
   sizing and the backtester decide "aligned" the same way. `remainder()`
   itself is unchanged.
2. `src/bot/main.ts` `generateGridsOnPrice`: `mod` is 0 when
   `gridRemainder(gridQty, step) === 0`. Otherwise it is the existing

   `remainder` → `gridRemainder`. The off-grid fallback is the same call.

helper lives on the existing `MathHelper`.
