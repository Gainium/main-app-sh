# 121 — Plan: keep Terminal limit orders out of the stuck-start sweep

## Solution

Move the sweep's DCA filter into `src/bot/dca/oldStartDealsFilter.ts`
(`oldStartDcaDealsFilter(now)`, pure, Tier 1 per the JIT runbook — a query
shape, no I/O) and replace the top-level `$not` with an equivalent `$nor`.
`closeOldStartDeals` calls it. The Combo half of the sweep is untouched.

## Blast Radius

1. Call sites: `closeOldStartDeals` is the only reader of this filter; it runs in
   the cron-jobs process (`src/server/cron.ts`), not the `app` process — a deploy
   has to restart cron-jobs for the fix to take effect.
2. The file is under `core/` (main-app-sh): commit in the submodule and bump
   main-app's pointer.
3. No GraphQL, socket, queue or schema change. The `dcadeals` read shape is
   narrowed only by the documented exclusion.
4. Existing tests on this path: none; `strandedStartClose` specs are unaffected.
