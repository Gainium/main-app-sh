# 140 — Combo take profit / stop loss reads each deal's own price (plan)

## Build order

1. `src/bot/comboTpSlOwnPrice.spec.ts`: red on the current code (§3.1, §3.2).
2. `comboHelper.ts` `unrealizedProfit()`: resolve the price per deal symbol,
   with the last-filled-order refresh done once per symbol per run (§4.1).
3. `dcaHelper.ts` `checkDealsPriceExtremum()` combo branch: the same
   formulas, grouped by deal symbol, with stale symbol keys removed (§4.2).
4. Version 1.87.2 + `CHANGELOG.md`.

## Decisions the spec left open

- Deals in `dealsForStopLossCombo` whose deal record is missing were already
  skipped by `unrealizedProfit()`. In the gate they now group under `''`
  rather than `pair[0]`. That key is never a tick symbol, so nothing changes
  for a deal the loop would skip anyway.
- The combo branch now deletes `highestLow` / `lowestHigh` keys it did not
  write, as the DCA branch does. For a bot with no levels this gives the same
  result as the old `pair[0]` → `0` / `Infinity` entry: the gate never fires.

## JIT tier

Tier 0. The defect is one wrong key in two methods. The fix keeps both
methods' shape and the existing formulas. Extracting either method would
widen a money-path diff with no gain.

## Blast Radius

1. Call sites. `unrealizedProfit()` is called only from the combo price
   callback (`comboHelper.ts`, extremum gate). `checkDealsPriceExtremum()` is
   called from several places in `comboHelper.ts` and `dcaHelper.ts`, and from
   main-app's parent `src/bot/comboHelper.ts`. None of them read the maps
   directly. The maps are only read by the price-callback gates, which key by
   `msg.symbol`.
2. `core/` submodule (`main-app-sh`). Shared by main-app's bot workers. The
   parent pointer must be bumped at ship.
3. Contracts. No GraphQL, REST, socket, queue or schema change. In-memory
   state only.
4. Behaviour change on multi-coin combo bots beyond §4.1. Ticks on coins other
   than `pair[0]` now pass the gate, so `checkDCALevel()` runs for them too.
   It already filters by `deal.symbol.symbol`, so this only restores level
   checks that were never reached. Single-coin bots key by the same symbol as
   before, so nothing changes for them.
5. Other tests. The full core mocha suite (`npm test`) must stay green.
