## Build order

1. `dca/positionReconcile.ts`: `reconcileDealAgainstVenue` also returns the held
   amount (`held`, absolute) when the venue holds a position. Additive.
2. `dcaHelper.reconcileDealPosition`: optional `onHeld(heldQty)`, called in the
   answered "position is there" branch after the existing clears. Every other
   caller passes no callback, so its behaviour is unchanged.
3. `combo/gridShortfallHold.ts` (new, pure): level key, deal fingerprint
   (`currentBalances.base` + `levels.complete`), the shortfall test, the message
   and `GRID_SHORTFALL_HOLD_MS` (6 h).
4. `comboHelper`:
   - `settleFlatDealAfterGridRefusal` collects refused closing levels per deal.
     While a hold is valid it adds them to the hold and does not probe. Otherwise
     it probes as before and passes `onHeld`.
   - `holdShortfallGridLevels`: if there is a shortfall, it takes the hold and
     sends the warning once per episode (`gsn` RetryBackoff, `attempt === 1`).
     If there is none, it clears the episode.
   - `placeOrdersHoldingDealLock` override: drops held levels from `orders.new`.
     A pass cancelling a closing-side grid ends the hold instead.
   - `clearClassProperties` resets both maps.

Decisions the spec left open: the hold is in memory (a reload re-sends once and
re-holds without re-announcing), and it lasts 6 h.

class; no legacy extraction.
